# Shivam Singh Patel - Personal Portfolio

A sleek, modern developer portfolio showcasing academic qualifications, certified professional internships, and live production deployments.

## 📁 File Structure
```text
├── index.html     # Structural markup containing customized resume items
├── style.css      # Custom styling tokens, layout alignments, and timeline grids
└── README.md      # This tracking manual file
```

## ⚙️ How to Deploy
1. Keep `index.html` and `style.css` in the same root folder.
2. Double-click `index.html` to run locally .
3. Push to a GitHub repository and turn on **GitHub Pages** within settings to make it live online for free!
